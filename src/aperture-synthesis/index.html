Capstone · real data

Now the real thing — a black hole.

Everything above is simulated. This is actual data: 51,119 visibilities the Event Horizon Telescope measured of M87* in April 2017 — the same numbers behind the first-ever image of a black hole. Run them through the exact pipeline above and see what the data alone gives you.

This is a simulation, not a single instrument — and that's the honest way to do it: the engine forward-models what an interferometer measures (the van Cittert–Zernike theorem, that visibility = the sky's Fourier transform), exactly as professional tools like eht-imaging and SYMBA do. The math behind every panel is real; the FFT is hand-rolled in src/fft.js so you can read it.

Simplifications, stated plainly: small-field approximation, and the w-term is ignored (standard for a narrow field). The capstone runs on real public data — the Event Horizon Telescope's First M87* Results visibilities from the April 2017 campaign (EHT Collaboration et al. 2019, ApJL 875, L1), released into the public domain under ODC-PDDL and regridded here to Stokes I.
